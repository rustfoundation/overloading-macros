This code is automatically run in CI:

- Submodules of `lib.rs` are expected to succeed. They are named after each C++ class.
- Examples are expected to fail, with output in the corresponding `.stderr` file, also named after C++ classes.

Sometimes the C++ code extracted by `cpp_build` will become outdated, and you will get errors like:

```text
error: This cpp! macro is not found in the library's rust-cpp metadata.
       NOTE: Only cpp! macros found directly in the program source will be parsed -
       NOTE: They cannot be generated by macro expansion.
...
error: cannot find macro `__cpp_closure_impl` in this scope
```

To fix these errors, run `cargo clean` then rebuild.
If the errors still happen after a clean, check your Rust and C++ code is compiling correctly.
